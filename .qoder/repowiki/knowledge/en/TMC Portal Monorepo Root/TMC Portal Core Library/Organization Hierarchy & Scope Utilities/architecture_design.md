Two complementary helper modules sit under `lib/` and depend on the Drizzle ORM layer (`@/lib/db`, `@/lib/db/schema`) plus NextAuth's `Session` type.
- `org-helper.ts` defines the typed tree node interfaces (`NationalNode`, `StateNode`, `LgaNode`, `BranchNode`) and exposes `getOrganizationTree`, which fetches all organizations in one query, groups them by `level`, and assembles the nested hierarchy via repeated `parentId` lookups; it also provides `getOrganizationAncestry` to walk parents upward from an org id.
- `org-utils.ts` offers a lower-level `getOrganizationHierarchy` that walks parent links using raw `db.select().from()` (chosen to avoid mysql2 compatibility issues), a `formatHierarchyNames` formatter, and `getOrganizationScope`, which derives the effective organization ID from a NextAuth session by checking super-admin status, official profile, explicit role selection, and roles array in priority order.
- Dependency direction is one-way: these helpers read from `db` and `next-auth` but are not imported by the database layer. Tests in `org-helper.test.ts` mock `./db` directly with Vitest to validate tree assembly without a live database.
