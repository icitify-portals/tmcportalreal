Flat collection of single-purpose modules under `lib/`, each exporting pure functions or small service-like utilities with no internal sub-packages. Dependencies flow outward to shared infrastructure: database access via `@/lib/db` and Drizzle ORM schemas (`auditLogs`, `members`, `programmes`, `offices`, `organizations`, `users`) is used by `id-generator.ts`, `audit.ts`, and `seed-planner.ts`; Redis connection via `ioredis` is centralized in `redis.ts` for BullMQ; Next.js server APIs (`next/headers` cookies) are used only in `mock-jurisdiction.ts`. Client-only code is isolated with a `'use client'` directive (e.g., `crypto.ts`), while server-only code uses `'use server'` (e.g., `seed-planner.ts`). Each file is self-contained and stateless except for module-level constants (e.g., crypto algorithms, default grading weights, country/state code maps).
