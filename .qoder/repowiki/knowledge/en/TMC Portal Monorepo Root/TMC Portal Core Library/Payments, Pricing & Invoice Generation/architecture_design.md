Three cohesive but independent utilities under `lib/`:
- `payments.ts` is the payment integration layer: it calls Paystack REST endpoints (`/transaction/initialize`, `/transaction/verify/{ref}`, `/subaccount`, `/bank`) via axios using secret/public keys from environment variables, persists payments through Drizzle ORM (`db.insert(payments)`, `db.update(payments)`), and on first-time success updates the associated fundraising campaign's `raisedAmount` and inserts an `INFLOW` row into `financeTransactions` (falling back to a national organization and the earliest user when IDs are missing).
- `pricing.ts` is a pure function module exposing `getEffectiveAmount`, `isEarlyBirdActive`, and `formatEarlyBirdLabel` over an `EarlyBirdFields` shape; it has no side effects and depends only on `Date` arithmetic.
- `invoice-generator.ts` is a presentation layer that builds PDFs with jsPDF + jspdf-autotable, rendering both invoices and receipts with a fixed TMC green color scheme and Naira-formatted amounts.
Dependency direction is one-way: callers import these three modules; they depend on `@/lib/db` (schema, Drizzle client), `axios`, `jspdf`, and environment variables, but do not import each other.
