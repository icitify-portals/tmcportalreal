Three-file module centered on NextAuth v5: `auth.config.ts` holds the framework-agnostic base config (JWT strategy, sign-in page, secret) so it can be imported without Node-specific imports; `auth.ts` composes the full `NextAuthConfig` by spreading that base, wiring the Drizzle adapter to the `users`, `accounts`, `sessions`, and `verificationTokens` tables, and registering a `CredentialsProvider` that validates email/password via bcrypt against the `users` table. A `populateTokenData` helper runs in the `jwt` callback to eagerly load role/permission graphs (`userRoles` → `roles` → `rolePermissions` → `permissions`) plus `members` and `officials` profiles into the token, and supports admin impersonation/revert flows via `session.action` triggers. The `session` callback mirrors token fields onto `session.user`. `session.ts` is a thin client-facing wrapper that calls the exported `auth()` route handler from `@/auth` and returns `null` on errors, providing a uniform `getServerSession()` API for server components.
