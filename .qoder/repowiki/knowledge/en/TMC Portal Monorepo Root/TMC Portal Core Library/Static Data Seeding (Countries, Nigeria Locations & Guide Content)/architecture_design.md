Four independent TypeScript modules under `lib/` that export plain data constants consumed by UI components — no runtime logic beyond simple lookup helpers. `countries.ts` defines a `Country` interface and an array of ~50 countries with ISO codes and phone prefixes, plus helper functions (`getCountryByCode`, `getCountryByPhonePrefix`, `getDefaultCountry`) to resolve entries. `nigeria-data.ts` exports `nigerianStatesAndLgas`, a flat array of all 36 states + FCT each carrying a `state` name and a `lgas` string array. `location-data.ts` exports a nested `locationData` object keyed by state name, where each state maps to an `lgas` array of objects with `name` and `branches` strings — used to populate dropdowns with branch-level locations. `guide-data.ts` imports Lucide React icons and exports a `GUIDES` array typed as `GuideModule[]`, where each entry is a self-contained help topic with id/title/icon/color/audience/summary and ordered `sections`. The module has no inter-file dependencies except `guide-data.ts` importing icons from `lucide-react`; it is purely declarative seed data with zero side effects.
