The `lib/` directory is organized as a flat collection of reusable modules consumed by both Next.js server actions (under `lib/actions/`) and page/server components. Cross-cutting concerns are split into focused modules: `auth.ts` + `auth.config.ts` wire NextAuth v5 with Drizzle; `rbac-v2.ts` and `rbac.ts` provide permission checks over those sessions; `org-helper.ts` / `org-utils.ts` resolve organization scope from session data; `payments.ts`, `pricing.ts`, and `invoice-generator.ts` handle Paystack flows and PDF invoicing; `email.ts`, `storage.ts`, and `queue.ts` expose Resend, S3/Wasabi, and BullMQ integrations; `db/schema.ts` defines the shared Drizzle schema used by all children; `ai/` configures LLM prompts/tools; `actions/` re-exports these services to implement per-feature server actions (members, finance, programmes, etc.). The module has no runtime entry point — it is imported directly by other packages, so cohesion comes from shared imports of `db`, `redis`, `session`, and `utils` rather than explicit wiring.
