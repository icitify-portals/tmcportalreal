This module is the top-level entry point of the Next.js App Router (`app/` directory). `layout.tsx` is the async root layout that exports Next `Metadata` (title, description, Apple web app config, manifest link) and a viewport object, then wraps every route in `<Providers>` (session provider), `<Toaster>`, `<SiteVisitor>` analytics, and `<AiChatWidget>`. `page.tsx` renders the public homepage: it fetches the national organization, community tree, galleries, latest fundraising campaign, and upcoming programmes via Drizzle ORM, composes them into CMS components (`HeroSlider`, `MissionVision`, `ExploreCommunity`, `ContactLocation`, `NewsFeed`), and renders a two-column layout with a footer. `not-found.tsx` reuses the dashboard shell to present a generic 404. `manifest.ts` generates the Web App Manifest for PWA support (standalone display, green theme color, 192/512 icons). `sw.ts` is a Serwist service worker that precaches assets from `__SW_MANIFEST`, enables runtime caching via `defaultCache`, and explicitly excludes Next.js Server Actions and `/dashboard/burial/new` from interception. `globals.css` defines the Tailwind v4 theme tokens, light/dark mode CSS variables, and four swappable color variants (green/blue/violet/orange) driven by a `[data-color=...]` attribute on the document root.
