The root is a single Next.js 16 project (standalone output) whose `app/` directory hosts the App Router segments for public, jurisdiction-scoped, authenticated dashboard, and REST API routes; these segments import cross-cutting services from `lib_core`, which in turn uses the MySQL schema defined under `database_schema` via both Drizzle (`drizzle.config.ts` pointing at `lib/db/schema.ts`) and Prisma (`prisma/` with its own migrations). Shared Radix-based UI primitives live under `shared_components/ui` and are consumed by feature modules throughout the app. Data access and business logic are centralized in `lib_core`, so pages and API routes stay thin. Ad-hoc maintenance scripts at the root (`migrate.ts`, `seed-drizzle.ts`, `fix*.sql`, `do_migrate.js`, etc.) operate on the same MySQL instance configured through `.env.local`. Deployment is orchestrated via `Dockerfile` + `docker-compose.yml` plus `deploy.sh`/`update_nginx.sh`, and CI workflows live under `.github/workflows`.
