Three small client-side React components that sit on top of `next-themes` and the project's shared `@/components/ui` primitives. `theme-provider.tsx` is a thin re-export of `NextThemesProvider`, exposing a uniform `ThemeProvider` entry used at the app root to supply theme context. `theme-components.tsx` consumes that context via `useTheme()` to render two interactive controls: `ThemeToggle`, a dropdown button switching between light/dark/system/green modes, and `ColorSwitcher`, which sets an orthogonal `data-color` attribute on `document.documentElement` so CSS can style accent colors independently of mode. Both components guard against hydration mismatch by deferring mount until after `useEffect`. `PageHeader.tsx` is a one-line compatibility shim that re-exports `PublicNav` as `PageHeader`, keeping older page imports working while directing new code to use `PublicNav` directly from `@/components/layout/public-nav`. Dependency direction is strictly outward: these helpers depend on `next-themes`, `lucide-react`, and `@/components/ui/*`; nothing in this scope depends on layout or page logic.
